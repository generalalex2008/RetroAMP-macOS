# RetroAMP

A lightweight retro-style music player for macOS.

## Features
- Retro / analog-inspired interface
- Multiple skins
- Playlist support
- Equalizer
- Album artwork display
  
## Required
- MacOS 13 with Apple M1 or Later

## Download

Download the latest version from the [Releases](../../releases) page  
or directly from this repository:

**[Download RetroAMP.dmg](./RetroAMP.dmg)**
